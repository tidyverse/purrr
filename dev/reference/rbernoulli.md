# Generate random sample from a Bernoulli distribution

**\[defunct\]**

This function was deprecated in purrr 1.0.0 and is now defunct because
it's not related to the core purpose of purrr.

## Usage

``` r
rbernoulli(n, p = 0.5)
```

## Arguments

- n:

  Number of samples

- p:

  Probability of getting `TRUE`

## Value

A logical vector
